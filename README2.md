# Назначение проекта
Наш проект представляет собой решение кейса "Умный кредитный кабинет предпринимателя" от "Альфа Будущее".
Созданный нами сайт помогает малому и микробизнесу пройти полный путь от потребности в финансировании до получения результата по заявке и заполнения документов.

Проект соединяет в себе несколько уже существующих сервисов Альфа Банка, а именно кредитный калькулятор, личный кабинет предпринимателя и очное рассмотрение кредитной заявки. Обученная нами модель помогает полностью делегировать рассмотрение заявки на автоматизированную и быструю систему.

# Архитектурное решение
Основной кредитный процесс представляет из себя следующие этапы:
**Вход/регистрация -> заполнение личных данных и данных о бизнесе (автоматическое дозаполнение происходит на основе ИНН) -> заполнение кредитной заявки -> список заявок и результат по ним -> заполнение документов при одобрении.**
Подробнее о пользовательских сценариях: [user-scenario.md](https://github.com/dashasevostianova/alfa-hack-2026/blob/documentation/docs/user-scenario.md)

Архитектура проекта включает в себя **фронтенд**, подключающийся к трем разным **бэкенд** блокам:
1. Бэкенд для общения с базами данных.
2. Бэкенд для загрузки актуальных ставок с кредитного калькулятора альфа банка.
3. Бэкенд для валидации инн и дозаполнения данных на основе Российской базы бухгалтерской отчетности.
а так же базы данных для сохранения пользовательских аккаунтов, заявок и результатов по ним.

Подробнее об архитектуре: [architecture.md](https://github.com/dashasevostianova/alfa-hack-2026/blob/documentation/docs/architecture.md)

Введенные данные сохраняются в безопасном формате (используется хэширование пользовательских данных, присутствует обработка ошибок), система динамично отображает состояние заявки и полностью реализует вышеописанный кредитный конвейер.
Продукт разработан под представителей малого и микробизнеса, поэтому пользование нашим сервисом не предполагает специальных технических или банковских знаний.

# Инструкции по запуску:
1. Склонируйте репозиторий с помощью `git clone https://github.com/dashasevostianova/alfa-hack-2026`
2. Назначьте собственные переменные окружения в .env файле на основе .env.example
3. Откройте Docker Desktop
4. Запустите проект из корневой папке с помощью `docker compose up --build -d --wait`
5. Откройте [http://127.0.0.1:8088/](http://127.0.0.1:8088/)
